# Portafolio de Josue Kennedy Yaranga Ruiz

Sitio estatico en HTML, CSS y JavaScript, sin dependencias ni proceso de compilacion; preparado para GitHub Pages.

## Contenido

- `index.html`: portada, presentacion, formacion, experiencia, proyectos, bitacora, reflexion final, bibliografia y contacto.
- `bitacora/semana-01.html` a `semana-14.html`: paginas basadas en el silabo IS093A.
- `css/style.css`: diseno adaptable.
- `js/script.js`: menu movil y ano automatico.

## Antes de publicar

1. Revisa que datos personales y certificaciones quieres hacer publicos.
2. Sustituye enlaces entre corchetes por URLs validas o eliminalos si aun no existen.
3. Completa tecnologias, contribuciones concretas, capturas y descripciones de proyectos.
4. Las paginas semanales parten del silabo: escribe practicas y reflexiones con tus apuntes y experiencia real. No presentes el silabo como evidencia de una actividad que no realizaste.
5. Personaliza la reflexion final al concluir el curso y conserva solo las fuentes que consultaste.

## Publicar con GitHub Pages

Sube el contenido a un repositorio. En GitHub, abre **Settings -> Pages**, elige **Deploy from a branch**, selecciona la rama (por ejemplo `main`) y la carpeta raiz (`/(root)`). Conserva las rutas relativas si el sitio vive bajo la ruta de un repositorio.

Guia oficial: [Quickstart de GitHub Pages](https://docs.github.com/en/pages/quickstart).
