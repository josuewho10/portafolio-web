CUADERNO DE APRENDIZAJE - SEMANA 01

Fundamentos de la Tecnología Web

Periodo: 2026-II | Asignatura: Desarrollo de Aplicaciones Web (IS093A)

1. Temas aprendidos (en mis propias palabras)

En esta primera semana sentamos las bases teóricas antes de escribir código. Entendí que no es lo mismo un sitio web (informativo) que una aplicación web (interactiva) o un sistema web (gestión de procesos complejos).

Comprendí cómo funciona la web a nivel de infraestructura: el DNS actúa como la "guía telefónica" que traduce nombres de dominio legibles a direcciones IP; el protocolo TCP/IP garantiza que los datos lleguen en orden y sin pérdidas; y HTTP es el lenguaje de petición y respuesta entre el cliente y el servidor. Finalmente, diferencié claramente los roles: el Frontend (lo que el usuario ve e interactúa, usando HTML/CSS/JS) y el Backend (la lógica, base de datos y servidor que procesa esa información).

2. Ejercicio de Laboratorio (Lab 01A)

Objetivo: Configuración del entorno de desarrollo y familiarización con Visual Studio Code (VSC).

  • Qué hice: Instalé y configuré Visual Studio Code como mi editor principal. Exploré su interfaz, el explorador de archivos y la terminal integrada.
  • Qué probé: Instalé extensiones clave para productividad, como Live Server (para previsualizar cambios en tiempo real) y Prettier (para formateo automático de código). Practiqué atajos de teclado esenciales, como ! + Tab para generar la estructura base de HTML5, y Ctrl + / para comentar líneas rápidamente.
  • Resultado: Un entorno de desarrollo optimizado, listo para subir mis primeras prácticas al repositorio de GitHub, estableciendo el flujo de trabajo que usaré durante todo el curso.

3. Dificultades y soluciones

Al principio, me costaba visualizar la diferencia práctica entre un "sitio web" y una "aplicación web", ya que los límites a veces parecen difusos. Lo resolví investigando ejemplos reales (ej. una página de noticias vs. un sistema de citas médicas como el que desarrollamos después) y discutiéndolo en las sesiones de clase. Aprendí que la complejidad de la lógica de negocio y la interacción con bases de datos es lo que define principalmente a un sistema o aplicación web.

4. ¿Qué aprendí y cómo aprendí? (Reflexión metacognitiva)

Aprendí que antes de escribir una sola línea de código, es fundamental entender el ecosistema en el que ese código va a vivir (DNS, HTTP, roles). Me ayudó mucho la estrategia de relacionar inmediatamente la teoría con la práctica: configurar mi VS Code y subir mis primeros ejercicios a GitHub me dio contexto real a los conceptos abstractos. La evidencia de este aprendizaje es este mismo portafolio electrónico, que aplica los estándares web desde su estructura. Me falta practicar profundizar en los estándares internacionales de accesibilidad (W3C) para que mis futuras aplicaciones sean inclusivas desde el día uno.
