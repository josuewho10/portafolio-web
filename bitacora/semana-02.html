CUADERNO DE APRENDIZAJE - SEMANA 02

HTML5, CSS3 y Diseño Responsivo

Periodo: 2026-II | Asignatura: Desarrollo de Aplicaciones Web (IS093A)

1. Temas aprendidos (en mis propias palabras)

Esta semana dimos el salto de la teoría a la estructura visual. Aprendí que HTML5 no es solo poner texto, sino construir un Árbol DOM semántico que los navegadores y los motores de búsqueda (SEO) puedan entender fácilmente. También entendí la diferencia entre XML (enfocado en transportar datos) y HTML (enfocado en mostrar datos).

En el lado del diseño, profundicé en CSS3. Comprendí la diferencia crucial entre unidades absolutas (px) y relativas (% , rem, vw/vh), y cómo estas últimas son la clave del diseño fluido. Finalmente, dominé los modelos de layout modernos: Flexbox (ideal para distribuir elementos en una dimensión) y Grid (para estructuras bidimensionales complejas), esenciales para lograr un verdadero diseño web responsivo que se adapte a cualquier dispositivo.

2. Ejercicio de Laboratorio (Lab 02A)

Objetivo: Aplicar diseño Flexbox, diseño fluido y diseño responsivo en una práctica individual.

  • Qué hice: Desarrollé una página web desde cero aplicando etiquetas semánticas de HTML5 y estructurando el contenido para ser compatible con distintos navegadores.
  • Qué probé: Implementé display: flex y display: grid para maquetar la estructura principal. Utilicé media queries (@media) para ajustar los tamaños de fuente y la disposición de los elementos en pantallas móviles, garantizando la fluidez del diseño.
  • Resultado: Una página web completamente responsiva, subida a mi repositorio de GitHub como evidencia de la práctica individual.
💻 Ver práctica individual en mi GitHub

3. Dificultades y soluciones

Al principio, me costaba visualizar cómo alinear elementos verticalmente con Flexbox y cuándo era mejor usar justify-content frente a align-items. Lo resolví utilizando herramientas visuales como "Flexbox Froggy" y revisando la documentación de MDN. Aprendí que la práctica deliberada con ejemplos pequeños es la mejor forma de internalizar estos conceptos antes de aplicarlos a proyectos grandes.

4. ¿Qué aprendí y cómo aprendí? (Reflexión metacognitiva)

Aprendí que un buen diseño responsivo no es un "parche" al final, sino que debe planificarse desde la estructura HTML. Me ayudó mucho la estrategia de inspeccionar elementos en el navegador (DevTools) para ver en tiempo real cómo afectaban mis cambios de CSS. La evidencia de este aprendizaje es el código de mi práctica individual en GitHub, donde apliqué media queries y Flexbox. Me falta practicar el uso avanzado de CSS Grid para layouts más complejos, ya que aún me siento más cómodo con Flexbox.

5. Registro de práctica

Fragmento de código de mi práctica donde aplico Flexbox y diseño responsivo con media queries: 

.contenedor-principal {
    display: flex;
    flex-wrap: wrap;
    gap: 1.5rem;
    justify-content: center;
}

/* Diseño responsivo para móviles */
@media (max-width: 768px) {
    .contenedor-principal {
        flex-direction: column;
        align-items: stretch;
    }
}
